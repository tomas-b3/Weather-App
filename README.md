# Weather Dashboard 🌤️

A simple Python weather app that uses the OpenWeather API to show weather information for a city.

## Features

* Search for a city
* Show current temperature
* Show weather conditions
* Show humidity
* Handle invalid city names

## How to Run

1. Clone the repository.
2. Install the required packages:

```bash
pip install requests python-dotenv
```

3. Create a `.env` file:

```text
API_KEY=your_api_key_here
```

4. Run the program:

```bash
python main.py
```

## Example

```text
Enter a city name: London

The weather in London is: Clouds
The temperature in London is: 15°C
```
